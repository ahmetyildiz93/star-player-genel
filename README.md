# Star Player – genel dosyalar

Bu depo yalnızca Star Player uygulamasının herkese açık olması gereken
dosyalarını içerir. Uygulamanın kaynak kodu burada değildir.

- [`config/remote.json`](config/remote.json): Uygulama içi duyuru, güncelleme
  uyarısı ve özellik ayarları. Düzenleyip kaydedince uygulamalar bir sonraki
  açılışta yeni ayarları alır. Ayrıntılar: [config/README.md](config/README.md)
- [`docs/PRIVACY.md`](docs/PRIVACY.md): Gizlilik politikası.
